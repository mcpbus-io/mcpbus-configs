# MCPBus config examples

There are number of MCPBus config examples categorized in folders of this repo. All config examples are validated and confirmed to be loading in Code-mode no problem.

Comand to load MCPBus with config:

```shell
mcpbus --config=path/to/your/mcpbus.conf
```

How to get MCPBus and for more information please refer to: [https://mcpbus.io](https://mcpbus.io)
